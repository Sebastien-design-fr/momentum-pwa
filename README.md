MOMENTUM v0.8 — PWA iPhone.

La branche dev/momentum-bridge livre un raccourci Apple signé : shortcuts/MOMENTUM Bridge.shortcut. La validation dans MOMENTUM transmet le titre, le créneau et l’alerte sans ressaisie. Installation, contrat, résultats de tests et limites : voir BRIDGE.md. Aucun service payant ; données conservées sous momentum.v1. main n’a pas été déployée par ce travail.
